# E-Commerce Sales Data Analysis

## 📌 Project Overview

This project analyzes e-commerce sales data to identify sales trends, profitability, product performance, customer patterns, and regional performance.

The project demonstrates an end-to-end data analysis workflow using Python, SQL, Excel, MySQL, and Tableau.

---

## 🎯 Objectives

- Analyze overall sales and profit performance
- Identify top-performing product categories and sub-categories
- Analyze regional and city-wise sales performance
- Understand quantity, discount, sales, and profit relationships
- Perform data cleaning and quality checks
- Extract business insights using SQL
- Create interactive dashboards and visualizations
